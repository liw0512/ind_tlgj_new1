# 塔级供浆策略设计（V2）

## 1. 核心边界

第二模块学习的是“哪一座塔应该增加/减少多少供浆，以及该动作历史上造成了怎样的 SO₂/pH 响应”，而不是学习操作员具体怎样分配每一个分阀门。

- 第一模块仍只负责 `jzfh × yyq_SO2` 工况识别。
- 第二模块经验主键保持粗粒度：`condition_label + 塔级动作`。
- pH、当前净烟气 SO₂、当前阀位继续保留为连续实时量，但不再继续离散组合成大量经验小桶。
- Normal 模式一次正式决策原则上只允许一座塔发生非 HOLD 动作。
- 多塔同时动作历史继续保存，作为审计和未来联合策略扩展的证据；Normal 模式暂不直接采用。

## 2. 塔级动作

同塔历史分阀动作统一归并为：

- `TOWER:xst|SUPPLY`
- `TOWER:apt|SUPPLY`

动作方向仍为 `INCREASE / DECREASE / HOLD`，幅度仍进行离散分档。

同一座塔无论历史上是只动阀1、只动阀2、两个阀一起动，主动作类型都不再因此拆开。原始分阀 delta 仍保留在 episode 中用于审计和后续执行分配。

塔级动作幅度采用该塔全部配置阀门的归一化净变化均值，避免阀门数量越多、动作幅度天然越大的问题。

## 3. 数据稀疏处理

新策略状态默认只有：

- `REGULAR`
- `TRANSIENT`

`condition_label` 已经是聚合外层主键，因此不再把下面这些字段继续拼入策略状态键：

- 一级塔/二级塔 pH 分档；
- 净烟气 SO₂ 区间；
- SO₂ 趋势；
- 各塔阀位区间；
- 多阀 BALANCED/UNBALANCED；
- 其他会导致同一工况继续大量拆桶的状态组合。

这些连续变量仍保留在原始 episode/实时输入中，只是不再成为经验桶主键。

## 4. 在线动态目标匹配

离线不绑定固定净烟气 SO₂ 目标。每个动作保存历史 `delta_outlet_so2` 分布。

在线计算：

```text
error = current_so2 - effective_target
predicted_so2_after = current_so2 + historical_delta_so2_median
predicted_remaining_error = predicted_so2_after - effective_target
```

同一经验层级内优先选择 `abs(predicted_remaining_error)` 更小的安全动作。

因此目标由 20 改到 15、18、25 等，不需要重新定义离线动作好坏；只需要在线重新计算当前动作与新目标的匹配程度。

## 5. 两塔 pH 的使用

一级塔动作主要用一级塔当前 pH 和一级塔历史 `ΔpH` 判断安全空间；二级塔动作同理。

pH 不再参与经验状态离散，而是在在线候选过滤时使用：

- 增浆：用历史 `ΔpH` P75 作为偏保守上行估计；
- 减浆：用历史 `ΔpH` P25 作为偏保守下行估计；
- 缺失时退回中位数。

```text
predicted_ph_after = current_ph + historical_delta_ph_guard
```

如果预测超过该塔 `ph_safe_range`，该塔当前动作直接过滤。

历史 pH 越界率继续作为解释和历史安全事实保存，不再新增额外厂级硬阈值；现有 `safety_history_score` 继续承担历史安全门槛。

## 6. 两塔动作选择

在线同一工况可以同时拿到：

- XST HOLD/INCREASE/DECREASE 候选；
- APT HOLD/INCREASE/DECREASE 候选。

系统按以下顺序决定：

1. 当前动态 SO₂ 目标需求；
2. 候选历史 SO₂ 响应是否匹配当前偏差；
3. 当前动作塔 pH 是否安全；
4. 历史响应稳定性和安全性；
5. 历史支持量和可靠性。

例如当前 `SO₂-target=+5`：如果一级塔 MEDIUM 历史响应更接近 -5，但当前一级塔 pH 已没有安全空间，而二级塔 MEDIUM 历史响应约 -4.2 且 pH 安全，则选择二级塔 MEDIUM，一级塔保持。

## 7. 分阀执行

塔级策略选定以后，再由执行层处理具体分阀。

新 `TOWER:<id>|SUPPLY` 动作不会照搬历史某次“阀1动、阀2不动”的分配习惯。执行层先从历史各分阀代表 delta 恢复塔级等效归一化动作，再映射到当前厂该塔的全部分阀，并继续执行：

- 阀门上下限；
- 单阀最大动作；
- 最小有效动作阈值；
- 最终 MainControl/DCS 联锁。

因此一阀、两阀、三阀电厂可以共享同一塔级策略思想。

## 8. 旧快照兼容

旧快照仍可能包含 pH/SO₂/阀位组合形成的细状态和 `BALANCED / VALVE:...|ONLY` 动作族。

在线候选读取保留兼容回退：如果新 `REGULAR/TRANSIENT` 状态不存在，会从旧细状态中按 action_id 选择历史可靠性、稳定性和支持量较高的档案继续提供候选。

但要完整启用新的“塔级动作 + 粗状态”经验结构，仍应重新执行第二模块初次训练或下一版本增量/重训，并按现有同版本激活流程发布新版本。
